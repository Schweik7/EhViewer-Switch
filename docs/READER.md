# 阅读器设计

阅读器默认使用 `720×1280` 逻辑画布。方向枚举描述的是**机身**怎么转：默认 `PortraitCounterClockwise` 表示机身逆时针转 90°，左手十字键在下方；为此画面以顺时针 90°输出到 Switch 的 `1280×720` 帧缓冲，逻辑左上角对应屏幕右上角。`PortraitClockwise`（十字键在上）和横屏保留为可选模式。0.3.1 及以前的实现方向相反，0.3.2 按实机反馈修正。

核心实现位于 `source/reader/ReaderCore.*`，不依赖 SDL/libnx，负责：

- 物理坐标、触摸点和方向键到旋转后逻辑坐标的双向映射；
- 默认单页、适应宽度，长图垂直滚动；
- 整页显示模式；
- 横屏可选双页及从右向左/从左向右排布；
- 当前页、后三页、前一页的预读顺序；
- RGBA 解码内存估算和默认 256 MiB 缓存预算。

竖屏模式始终强制单页。页面应先绘制到竖屏逻辑纹理，再以 CCW 方向旋转到物理屏幕。下载线程只负责压缩图像文件；解码位图和 GPU 纹理都必须计入阅读缓存预算。

## SDL 实现（`source/ui/ReaderView.*`）

- 解码线程：`IMG_Load` → 转 `ABGR8888`；仅当超过 GPU 最大纹理尺寸（上限 4096）时缩小。
- UI 线程：把解码好的 surface 建成纹理；只保留预读窗口内的页面，超过 `MemoryBudget` 时从最远的非可见页开始淘汰。
- 绘制：先画到逻辑画布（渲染目标纹理），再用 `SDL_RenderCopyEx` 以 +90°（SDL 角度顺时针为正）居中输出。
- 边下边读：阅读器按 `PageDirectories()`（先 `galleries/`、再 `.incoming/`）逐页查找 `p_<n>.<ext>`；还没下载到的页面显示“等待下载”和转圈，每 1.5 秒重查。
- 页码指示在画布右下角；打开、缩放、旋转后 4 秒显示标题和操作提示。
- 退出（`B` 或 `+`）时把当前页写回 manifest 的 `currentPage`。

## 按键

方向输入先经 `PhysicalToLogical` 转为逻辑方向，所以旋转后“下”永远是画面向下。

| 按键 | 作用 |
| --- | --- |
| 十字键/左摇杆 逻辑下 | 向下翻一屏，已到底则下一页 |
| 十字键/左摇杆 逻辑上 | 向上翻一屏，已到顶则上一页（定位到页尾） |
| 十字键/左摇杆 逻辑右/左 | 下一页/上一页 |
| 右摇杆 | 连续滚动 |
| `A` / `R` / `ZR` | 下一页 |
| `L` / `ZL` | 上一页 |
| `Y` | 适应宽度 ↔ 整页 |
| `X` | 旋转：逆时针竖屏 → 顺时针竖屏 → 横屏 |
| `-` | 横屏时切换单页/双页 |
| `B` | 返回并保存进度 |
